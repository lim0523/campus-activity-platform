# 需求分析

## 项目名称

校园活动报名与签到系统

## 背景

学校中经常存在讲座、社团活动、比赛、志愿服务等活动。传统报名方式依赖群通知、表格收集或现场纸质签到，容易出现报名信息分散、名额统计不准、签到记录难整理、活动效果难评估等问题。

本系统面向校园活动组织和参与场景，提供活动发布、活动报名、签到管理、反馈评价和统计查询能力。

## 用户角色

- 学生：浏览活动、报名活动、取消报名、查看个人报名记录、提交反馈。
- 组织者：发布活动、管理活动、查看报名名单、执行签到、查看活动统计。
- 管理员：管理用户、活动分类、系统基础数据，查看整体统计。

## 核心功能

- 用户与角色管理
- 活动分类管理
- 活动发布与状态管理
- 活动报名与取消报名
- 活动签到记录
- 活动反馈评价
- 活动报名与签到统计

## 业务规则

- 一个用户可以拥有一个角色。
- 一个活动必须属于一个活动分类。
- 一个活动由一个组织者创建。
- 一个学生对同一活动只能存在一条报名记录。
- 只有报名成功或已参加状态的报名记录才能签到。
- 一个报名记录最多对应一条签到记录。
- 活动达到人数上限后，不应继续接受新的成功报名。
- 活动取消后，不应继续报名或签到。
- 活动结束后，学生可以提交反馈评价。

## 功能边界

本课程作业不实现真实支付、复杂消息推送、二维码动态安全校验、移动端适配和文件上传服务。

如需页面展示，可以保留简单的活动封面字段，但数据库设计不依赖图片上传功能。

## 典型查询需求

- 查询可报名活动列表。
- 查询某活动的报名名单。
- 查询某活动的签到名单和未签到名单。
- 查询某个学生的活动参与记录。
- 统计各活动的报名人数、签到人数和签到率。
- 统计各分类下活动数量和报名总人数。
- 查询热门活动排行。
- 查询组织者发布活动的整体报名情况。
